# RideOS Android

RideOS is an Android cycling computer and telemetry platform designed for cyclists and electric bikes.

## Project goals

- Modern Android dashboard
- GPS ride tracking
- BLE connectivity
- VESC telemetry integration
- Battery and energy analysis
- Ride history and statistics
- Diagnostics and alerts

## Initial technology direction

- Kotlin
- Jetpack Compose
- Android BLE
- Room for local ride data
- Modular architecture
